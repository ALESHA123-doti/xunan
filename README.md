# XUNAN — сайт компании

Адаптивный сайт из четырёх страниц: главная, каталог, карточка автомобиля и расчёт стоимости. В каталоге используются 24 записи из файла автомобилей, добавлены фильтры, поиск, сортировка и места под 22 фото на каждую машину.

## Запуск

Требуется Node.js 18 или новее. В папке проекта выполните:

```sh
node server.js
```

Откройте `http://127.0.0.1:8000`. Сервер отдаёт сайт и получает актуальный курс CNY из официального XML-сервиса Банка России. Если курс временно недоступен, интерфейс использует резервное значение 12,61 ₽/¥ из приложенной расчётной таблицы и помечает его как резервное.

## Данные и уточнения перед публикацией

- `cars-data.js` содержит данные из приложенной таблицы. Описания комплектации, VIN/номера кузова и состояние нужно подтвердить для конкретных машин перед публикацией.
- Ориентир в рублях в каталоге пока показывает только пересчёт цены в юанях. Пошлины и доставка требуют расчёта отдельно: в расчётной таблице заполнена доставка не была, а таможенная сумма указана как пример для 106 500 ¥.
- Поле `leadEmail` в `site-config.js` пока пустое. После ввода адреса форма сформирует письмо в почтовом приложении посетителя; для автоматической отправки через сервер потребуется подключить почтовый сервис.
- Исходные `assets/logo.png` и `assets/favicon.ico` скопированы без изменений. Фотографии автомобилей пока заменены плейсхолдерами; предполагаемые пути — `assets/cars/0/01.jpg` … `22.jpg` и отдельные папки для других машин.
- Таможенное оформление выполняет покупатель; XUNAN доставляет автомобили до Уссурийска и может рекомендовать брокера-партнёра.
