# XUNAN — сайт компании

Адаптивный сайт: главная, каталог, карточка автомобиля, расчёт стоимости и анкета «Машина на заказ». В каталоге 24 записи, фильтры, поиск, сортировка и плейсхолдеры под фотографии.

## Запуск локально

Требуется Node.js 18 или новее. В терминале из папки проекта выполните:

~~~sh
node server.js
~~~

Откройте http://127.0.0.1:8000. Если порт уже занят, можно запустить сайт на другом порту в PowerShell:

~~~powershell
$env:PORT=8001
node server.js
~~~

После этого откройте http://127.0.0.1:8001.

## Курс валюты

Сервер запрашивает CNY/RUB из официального XML-источника Банка России. Страница обновляет курс сразу при открытии, затем каждые 30 минут и после возвращения во вкладку. При временной ошибке используется резервный ориентир 12,61 ₽/¥ с пометкой. Курс ЦБ является ориентиром; условия расчёта перевода могут отличаться.

## Анкета «Машина на заказ»

Поля автомобиля необязательные. Для заявки нужно выбрать канал связи и указать адрес/номер/контакт в выбранном канале. Адрес получателя в site-config.js настроен на xunan2026@mail.ru. При отправке браузер открывает почтовое приложение с заполненным письмом; посетителю нужно нажать «Отправить». Для отправки письма напрямую с сайта без почтового приложения понадобится подключить почтовый сервис и его серверные реквизиты.

## Перед публикацией

- cars-data.js содержит 24 записи из предоставленной таблицы. Описания, состояние и цены автомобилей нужно подтверждать перед публикацией.
- В расчёте стоимости пошлина 526 532,7 ₽ — пример для 106 500 ¥. В первой записи каталога Audi Q3 указана цена 170 000 ¥, а доставку нужно вводить отдельно; эти суммы требуют сверки.
- Фотографии пока заменены плейсхолдерами; галерея рассчитана на 22 изображения на автомобиль.
- XUNAN доставляет автомобили до Уссурийска, но не выполняет таможенное оформление; компания может рекомендовать брокера-партнёра.
- Исходные assets/logo.png и assets/favicon.ico оставлены без изменений.
